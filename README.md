# JavaScript Operators and Conditions

This repository contains solved practice examples of JavaScript operators and conditional statements.

Topics Covered:

- Arithmetic Operators (+, -, *, /, %)
- Assignment Operators (=, +=, -=)
- Comparison Operators (==, ===, !=, !==, <, >, <=, >=)
- Logical Operators (&&, ||, !)
- Unary Operators (++, --)
- Ternary Operator
- if, else if, else
- switch statement
- Mini Real World Problem (Shopping Discount)

Examples include shopping calculations, login checks, age validation, and exam results.

Created for learning and practice.
